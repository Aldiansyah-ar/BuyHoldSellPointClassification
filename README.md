# Classification of Buy, Hold, and Sell Points for US Electronics Company Stocks Using Convolutional Neural Networks
<p style="text-align: justify;">
  Investor decisions in stock management rely on identifying optimal buy, hold, and sell points to determine the best asset strategy and minimize risk. Stock data from technology companies including Apple Inc., HP Inc., and Microsoft were transformed into image formats to enable the classification of buy, hold, and sell points using the CNN algorithm.
</p>

## Data Collection
The stocks data are gathered from https://stooq.com and https://alphavantage.co

## Stack
Python (Scikitlearn, Tensorflow)

## Setup
Clone the repository
```bash
git clone https://github.com/Aldiansyah-ar/BuyHoldSellPointClassification
```
Direct to the project directory
```bash
cd BuyHoldSellPointClassification
```
Create the `Python Environment`

```bash
python -m venv venv_name
```
Activate the environment
```bash
venv_name\scripts\activate.bat
```
Install the library in `requirements.txt`
```bash
pip install -r requirements.txt
```
